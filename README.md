Recursos Informáticos

Objetivo
Este proyecto sirve para recopilar y organizar recursos informáticos útiles para estudiantes y personas interesadas en la informática.

Funcionalidades
- Mostrar recursos informáticos recomendados.
- Incluir enlaces a páginas de aprendizaje.
- Aplicar estilos básicos a la página web.

Estructura del proyecto
- `index.html`: contiene el contenido de la página web.
- `style.css`: contiene los estilos de la página.
- `README.md`: explica el objetivo y la estructura del proyecto.
- `.gitignore`: indica qué archivos no se deben incluir en el control de versiones.

Instrucciones de uso
1. Descarga o clona el repositorio.
2. Abre el archivo `index.html` en un navegador.
3. Utiliza los enlaces de la página para acceder a los recursos informáticos.

Tecnologías utilizadas
- HTML
- CSS
- GitHub
